Личное приложение

rclone-transfer

Перенос собственных файлов из Яндекс Диска в Google Диск с помощью rclone.

Приложение используется владельцем для копирования файлов, сохранения структуры папок и проверки результатов переноса. Это персональная настройка rclone, а не публичный сервис регистрации пользователей.

Как проходит перенос

Владелец разрешает доступ к своим облачным аккаунтам на страницах их провайдеров. Копирование выполняется на управляемом владельцем сервере. Содержимое файлов передаётся через сервер в Google Диск; журналы фиксируют ход работы и ошибки.

Текущий режим копирования сохраняет исходные файлы и пропускает уже совпадающие файлы назначения. При конфликте содержимого существующий файл не перезаписывается.

Доступ к Google Диску

Приложение запрашивает разрешение drive.file: доступ к файлам и папкам, созданным приложением или явно предоставленным ему пользователем. Оно используется для создания копий, чтения метаданных и проверки результатов. Разрешение не предоставляет доступ ко всем остальным файлам Диска.

Этот сайт содержит только описание приложения. Здесь не выполняется вход в Google и не загружаются файлы. Пароли вводятся только на страницах соответствующего провайдера.

Конфиденциальность и связь

Подробности доступа, хранения и удаления данных описаны в политике конфиденциальности. Связаться с владельцем можно через обращение в репозитории GitHub. Не включайте в публичное обращение токены, пароли или содержимое личных файлов.
